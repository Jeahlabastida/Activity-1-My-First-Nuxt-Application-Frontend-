# Nuxt Personal Profile

Two-page personal profile website built with Nuxt 4 and Tailwind CSS v4.

## Setup
```bash
npm install
npm run dev      # http://localhost:3000
```

## Structure
- `app/pages/index.vue`   – Homepage
- `app/pages/profile.vue` – Profile page
- `app/components/`       – AppNavbar, SectionCard
- `app/layouts/default.vue` – Shared layout (navbar + footer)
- `public/`               – Static files (avatar.svg)
